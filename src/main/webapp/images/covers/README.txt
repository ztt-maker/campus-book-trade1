示例教材封面目录

首页 8 本示例教材会读取本目录下的图片，文件名必须与下面一致（jpg 格式）：

java-web.jpg              Java Web程序设计
linear-algebra.jpg        线性代数（第六版）
physics.jpg               大学物理（上册）
os.jpg                    操作系统概念（第九版）
probability.jpg           概率论与数理统计（第四版）
discrete-math.jpg         离散数学（第五版）
software-engineering.jpg  软件工程导论（第六版）
marxism.jpg               马克思主义基本原理概论

把对应的封面图片放进本目录即可显示；没有放图时，页面会自动显示“暂无封面”。

注意：用户自己发布的教材图片由 UploadUtil 保存到 webapp/images/ 目录，
与这里分开管理，不要混在一起。
